# 클론 코딩 작업

아래 예시 이미지를 참고해서 클론 코딩을 만들어 줘.

## 예시 이미지 (Few-shot)

- $ARGUMENTS
- 이미지가 여러 장이면 모두 참고한다.

## 1. 기술 스택 확인

- 작업을 시작하기 전에 어떤 기술로 만들지 먼저 물어본다. (예: HTML/CSS/JS, React)

## 2. 구현 기준

- 레이아웃, 색상, 폰트를 예시 이미지와 최대한 똑같이 맞춘다.

## 3. 하지 말아야 하는 것들

1. CSS 애니메이션 사용 금지 (`@keyframes`, `transition`, `animation` 등)
2. JS 이벤트 효과 사용 금지 (hover 효과, 스크롤 효과, 클릭 시 동적 변화 등)
